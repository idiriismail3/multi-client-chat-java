# Submission checklist

- [ ] Run `mvn clean package` from the project root and confirm `BUILD SUCCESS`.
- [ ] Verify the server and at least two clients run on the target machine.
- [ ] Demonstrate group messaging, `allUsers`, blank-username read-only mode, and disconnect.
- [ ] Include both Maven modules and all source files in the GitHub repository.
- [ ] Include `README.md`, `docs/class-diagram.puml`, and `docs/deployment-diagram.puml`.
- [ ] Include the two generated JAR files if required by the instructor; state their runtime requirements accurately.
- [ ] Record a roughly three-minute demo using `docs/demo-video-script.md`.
- [ ] Add the GitHub repository URL and demo video URL to the submission message.
- [ ] Keep a local backup of the final source and artifacts.
